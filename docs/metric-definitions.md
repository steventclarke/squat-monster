# Metric Definitions (V1)

- Speed: vertical velocity, concentric phase only (m/s)
- Force: F(t)=m(a_y+g), m = total external load including bar (kg), g=9.80665 m/s^2, reported in N (no bodyweight)
- Bar position: center of largest near-side plate
- Verticality: max/RMS horizontal deviation and range from vertical line at concentric start
- Smoothing: ~150 ms (tuned for acceleration stability)
- Rep-to-rep comparison within set only
- Force shown only if valid load and stable acceleration; otherwise marked unavailable
